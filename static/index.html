How to Use

  1. Press Start Camera and allow camera access.
  2. Show a trained gesture (e.g. from your collected vocabulary).
  3. Wait for the current prediction to stabilize.
  4. Press Add Sign (or the keyboard shortcut A) to append it to the sentence.
  5. Use Space, Delete, and Clear to edit.
  6. Press Speak to hear the sentence aloud (browser voice).
Keyboard shortcuts
KeyAction
AAdd current sign to the sentence
SpaceInsert a space between words
BackspaceDelete the last token
EscClear the sentence

Privacy: camera input is processed live for sign recognition only and is not intentionally stored during normal inference. Frames are never sent outside your computer (this app, including classification, runs locally).

Recognizes only gestures included in the trained vocabulary. This is a research/educational prototype, not complete sign-language interpretation.
